## Zaroori baatein
- Jahan `sudo` likha hai wahan root/admin access chahiye.
- Lab 8 (rpm/dnf) sirf Red Hat family (RHEL / Rocky / AlmaLinux) par chalega. Baaki labs Ubuntu/Kali/RHEL par chalte hain.
- Lab 9 aur 10 mein **sirf test disk / loop device** use karo. System disk (`/dev/sda`, `/dev/nvme0n1`) par kabhi `mkfs`, `fdisk` ya `parted` mat chalao.
- Device names (`/dev/loop0`, `/dev/loop1p1`, PIDs, UUIDs) har system par alag honge. Apne system ke output ke hisaab se badlo.
- Practical file/record mein apne terminal ke output ke screenshot lagana.
